Check a plate object (compatibility name from MycoHalo)

``` r
is_mycohalo_plate(plate)
```

## Arguments

- plate:

  A plate object.

Logical; delegates to
[`is_funmel_plate()`](https://mghotbi.github.io/FunMel/reference/is_funmel_plate.md).
