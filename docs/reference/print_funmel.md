# Print a FunMel object summary

Summarizes a plate image, layout, classifier or completed analysis.

## Usage

``` r
# S3 method for class 'funmel_result'
print(x, ...)

# S3 method for class 'funmel_classifier'
print(x, ...)

# S3 method for class 'funmel_layout'
print(x, ...)

# S3 method for class 'funmel_plate'
print(x, ...)
```

## Arguments

- x:

  FunMel object to summarize.

- ...:

  Additional arguments for the generic; currently unused.

## Value

The input object invisibly.
