FunMel 0.4.7 validation

Mandatory metadata approval has been removed throughout coefficient calculation,
finalization and plotting. New templates and supplied example metadata do not
generate a metadata_confirmed column. Existing user-supplied columns, including
review records, are preserved without a metadata approval gate. Informative
review reminders do not block valid processing. The optional strict image-QC
policy remains opt-in; it is never used by the standard workflow.

Structural checks remain: experimental labels must be complete, every treatment
uses controls from its own set, analyzed plate identities must match, changed
image-layout settings require reanalysis, and failed images prevent finalization.
No automatic experimental or image approval is claimed.

Full test suite: 484 passed, zero failures, zero warnings, zero skips.
The actual uploaded eight-plate saved analysis was finalized with every supplied
metadata_confirmed value still FALSE. No images were reprocessed, all measured
MI values were preserved, both matched coefficients were generated and PDF/SVG/
PNG figures exported. The coefficients were 1.628250 and 1.302033 (rounded).
One control per set limits this case to descriptive results. These are image-
darkness ratios, not melanin concentration ratios or significance tests.

R CMD check --as-cran --no-manual --no-tests: zero errors, zero warnings and two
NOTEs (installed size due to original photographs; current system time could not
be verified). Tests ran separately as above. Examples, --run-donttest examples,
help checks and vignette rebuilding passed within the package check. Validation
used an external temporary Makevars to avoid distribution-specific compiler flag
NOTEs; that environment workaround is not shipped as user code.

Image-processing sources (background, analyze, detect_plate, segment, measure,
classify and spots) were compared byte-for-byte against 0.4.6 and are unchanged.
The illumination safeguard and all eight original JPEGs are retained. Existing
teaching measurements retain their stated illustrative calibration/provenance;
the software change concerns approval gates, not measurement algorithms.

README, vignette, installed vignette, help, examples, scripts, metadata templates
and rendered website were updated. Public workflow guides no longer contain
metadata confirmation-switch instructions. The website has 51 HTML pages and
18 verified PNGs, with no missing local assets or file:// links. A container-only
PID/rendering workaround was used without adding it to the package. The code
font, logo and site design are retained. Both downloads are under 25,000,000 bytes.

Computation is not biological validation. Check experimental assignments before
analysis and masks, sampling, calibration, illumination and warnings before
interpretation. These responsibilities are reminders, not mandatory checkboxes.
